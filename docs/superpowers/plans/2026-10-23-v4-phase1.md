## Decisions and risks

- Adjacent distinct calendar dates are separate observations; no arbitrary
  one-day tolerance for labs/drugs. Invalid/one-sided dates need human review.
- Last-consultation date is an exclusive calendar-day boundary; an approved
  packet timestamp/ledger sequence can form a more precise baseline. Never
  substitute upload date for unknown observation date.
- Incomparable source units and ambiguous same-day values suppress arithmetic.
- New schema uses tenant-qualified references and no fabricated guideline
  coordinates. Later-phase services must enforce their own RBAC/audit/approval.
- Existing uncommitted changes are retained; edits are confined to Phase 1.
- User authorized independent research/review agents. Schema and OCR work have
  disjoint ownership; the primary agent owns domain/extraction and integration.

## Review focus

- Serial observations must not become members of unrelated same-day conflicts.
- Undated evidence must remain visible without a fabricated date or agreement.
- Reopened conflicts count once per conflict, using event timestamps.
- Replaced/rejected/superseded facts must not drive numeric deltas.
- OCR errors/partial pages must never produce a misleading `ready` document.

Security assumptions and rationale: ADRs 0019 and 0020 accompany implementation.
