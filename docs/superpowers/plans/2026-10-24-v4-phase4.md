# Phase 4 Oncology Guideline Co-Pilot and Clinician Productivity Studio Checklist

Goal: Implement tasks 4.1 and 4.2 only, preserving Phase 1, 2, and 3 working-tree changes.
Architecture:
- Guideline retrieval: Version-pinned institutional oncology SOPs and NCG reference guidelines queried via PostgreSQL full-text/keyword matching with exact verbatim text and source bounding boxes. Routed via `guideline_knowledge_question` in the assistant classifier; patient-specific clinical recommendations remain blocked.
- Assistant fixes & grounding: Correct `openTasksCount` in `tools.ts` to query `listTasks(q, patientId)`. Citation validation gate rejects invalid/fabricated citations, cross-tenant leaks, and withdrawn sources.
- Productivity Studio: Pure domain draft generators in `packages/domain/src/studio/draft-generator.ts` for 4 formats (Referral Letter, Tumor Board Deck, De-identified Academic Case Abstract, Patient Info Sheet) with `[E#]` and `[G#]` citations, de-identification privacy validation, editable drafts, clinician approval, immutability, and export formats.
